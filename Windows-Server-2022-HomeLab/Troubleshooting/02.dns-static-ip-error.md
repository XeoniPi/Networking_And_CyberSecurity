# Troubleshooting: DNS Installation Static IP Error

## Problem Description
During the DNS Server role installation on Windows Server 2022, the validation wizard displays the following warning/error:
> **"No static IP addresses were found on this computer"**

### Why this happens
A DNS Server must have a fixed identity. If the server uses a dynamic IP (DHCP) and the IP changes, client computers will lose connection to the DNS server. Microsoft forces a validation check to ensure a static IP is configured before proceeding.

---

## Solution: Configure Static IP on Host-Only Adapter

Follow these step-by-step instructions to assign a permanent IP address to the server.

### Step 1: Open Network Connections
1. Log into your **Windows Server 2022** (Server22).
2. Open **Control Panel** -> **Network and Internet** -> **Network Connections**.
3. Identify your **Host-Only Adapter** (usually named *Ethernet 2*).

### Step 2: Configure IPv4 Properties
1. Right-click on the Host-Only Adapter and select **Properties**.
2. Select **Internet Protocol Version 4 (TCP/IPv4)** from the list.
3. Click the **Properties** button.
4. Choose **"Use the following IP address"** and enter these exact details:

| Field | Value | Note |
| :--- | :--- | :--- |
| **IP address** | `192.168.56.103` | Your designated Homelab Server IP |
| **Subnet mask** | `255.255.255.0` | Standard Class C mask |
| **Default gateway**| *Leave Blank* | Not needed for isolated Host-Only setup |
| **Preferred DNS** | `192.168.56.103` | Server points to itself for DNS resolution |
| **Alternate DNS** | *Leave Blank* | None |

5. Click **OK** and then **Close** to save the changes. *(No reboot required)*

---

## Verification & Next Steps

1. Relaunch the **Add Roles and Features Wizard** from Server Manager.
2. Select the **DNS Server** role and proceed through the prompts.
3. The validation error will no longer appear, and the installation will complete successfully.

## Summary Rule
* **DNS Server** = Requires **Static IP**
* **DHCP IP** = Invalid configuration for core infrastructure servers
