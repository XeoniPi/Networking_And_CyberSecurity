# Networking & Cybersecurity Labs

## 📌 About
Welcome to my Networking & Cybersecurity learning repository.

This repository documents my hands-on journey in networking, system administration, Windows Server, Linux, virtualization, scripting, and cybersecurity. It contains lab guides, technical documentation, notes, screenshots, and automation scripts created while building real-world home lab environments.

## 🎯 Objectives

- Build practical IT infrastructure skills
- Learn enterprise networking technologies
- Practice Windows Server administration
- Gain Linux system administration experience
- Explore cybersecurity concepts and tools
- Document every lab for future reference
